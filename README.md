# lista-01-udwmj

### Código JavaScript ###

Nomes:Eliseu Pereira da Silva, Daniel Amorim Monteiro Barbosa, Paulo Henrique Gonçalves Botelho da Silva, Sabrina Abade Fernandes Ribeiro. 

O código em JavaScript calcula a média de três notas de um aluno.

## Funcionamento: ##

O programa possui três notas armazenadas em variáveis. Em seguida, soma as três notas e divide o resultado por 3 para encontrar a média.

## Exemplo ##

**Notas:**

- Nota 1: 8
- Nota 2: 7
- Nota 3: 9

Resultado:

**Média:** 8
